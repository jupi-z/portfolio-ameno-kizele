# Portfolio evidence policy

Case studies separate inspected source, test files, observed CI runs, local QA reports and material available only on request. A link is described only to the extent supported by the cited file, commit or run.

- A test file being present is not described as a test run.
- A successful CI run is tied to its URL and exact commit; it is not treated as proof of production readiness.
- Local QA is labelled local and dated by its source report.
- Repository URLs that were not accessible anonymously during the 28 November 2026 review are not presented as public links. This observation does not by itself establish why access failed.
- Business outcomes and performance figures are omitted unless a dated, defined and attributable source exists. Where relevant, case studies state that commercial impact is not measured or documented.
- Project images in the portfolio are design illustrations. They are not represented as screenshots from a live product.
- Evidence requests open the contact page with a project-specific subject; no private source is linked from public pages.

Observed public proof references and exact pins are maintained in `src/data/projects.ts`. Review them again before changing any visibility or claim.
